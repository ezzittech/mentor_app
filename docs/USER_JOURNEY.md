# السيناريو من البداية إلى النهاية (مختصر)

**قبل المتدرب**
1. المرشد يسجّل (أريد أن أكون مرشدًا) ← يملأ الملف والباقات ← «إرسال للمراجعة».
2. المسؤول يراجع ويعتمد ← يظهر المرشد في الدليل العام.

**المتدرب**
1. يسجّل حسابًا (يحدد لغته ومنطقته الزمنية تلقائيًا) ← يؤكد بريده.
2. يملأ **التقييم الأولي**: الهدف، الخلفية، الفجوات، الوقت المتاح، التاريخ المستهدف.
3. يتصفح الدليل ويصفّي حسب المجال والمهارة واللغة والسعر ← يفتح ملف مرشد ← يختار باقة.
4. يرسل **طلب إرشاد** يشرح فيه هدفه. (لا دفع الآن)

**المرشد**
5. يصله إشعار ← يفتح الطلب (يصبح «قيد المراجعة») ← يقرأ هدف المتدرب وتقييمه.
6. **يقبل** (أو يعتذر مع السبب) ← تنشأ علاقة الإرشاد + فاتورة معلقة + محادثة خاصة برسالة ترحيب.
7. يراجع التقييم: «يحتاج معلومات» أو «تمت المراجعة».

**المتدرب والمرشد: بناء الخطة**
8. المرشد ينشئ **خطة التطوير**: أهداف (نقطة البداية، المستهدف، دليل الإنجاز) ← مراحل ← مهام ← مصادر تعلم.
9. «إرسال للموافقة» ← المتدرب يراجع: **يعتمد** (فتبدأ العلاقة ويصبح الإرشاد «نشط») أو يطلب توضيحًا فتعود مسودة.

**التنفيذ**
10. المتدرب يبدأ مهمة ← ينفذها ← **يسلّم** (نص + رابط).
11. المرشد يراجع: **اعتماد** (المهمة تكتمل) أو **طلب تعديل** مع ملاحظات ← يعيد المتدرب التسليم.
12. تتحرك نسب التقدم تلقائيًا (المهام ← الهدف ← الخطة).
13. المرشد يجدول **جلسات** (وقت + رابط Zoom/Meet + جدول أعمال) ← تصل المتدرب إشعارًا ← تنعقد الجلسة ← يسجّلها المرشد «مكتملة» مع ملاحظات مشتركة.
14. محادثة فورية بين الاثنين طوال الوقت.

**المشرف والإدارة**
15. المسؤول يسند **مشرفًا** للعلاقة ← يصله إشعار.
16. المشرف يتابع لوحة الخطر (مهام متأخرة، خمول، جلسات فائتة) ← يكتب ملاحظات (له وحده / للمرشد / للمتدرب) ← يسجل تدخلات (تذكير، تصعيد…).
17. المسؤول يؤكد **الدفع** ← يصل المتدرب إشعار ← تُحسب أرباح المرشد بعد العمولة.

**الإغلاق**
18. تكتمل الخطة والأهداف (محققة / جزئيًا / غير محققة) ← تنتهي العلاقة.
19. المتدرب يضع **تقييمًا** للمرشد ← يظهر في ملف المرشد (بالاسم الأول).
20. كل خطوة حساسة مسجلة في **سجل التدقيق**.

> الخطوات 18–19 تعمل جزئيًا اليوم؛ التفاصيل في `JOURNEY_REPORT.md`.
